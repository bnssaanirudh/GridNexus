# Final Claim Scope

**Purpose**: Freeze the scientific contribution before drafting the manuscript.

## SUPPORTED CLAIMS
1. **Coalition-constrained energy-market architecture**: GridNexus contains a software architecture that links P2P energy negotiation, physical-network feasibility checks, stability checks, and settlement certification.
2. **Physically mapped settlement guard**: The settlement API now rejects proposed trades whose seller or buyer cannot be mapped to an explicit grid node. It no longer silently substitutes the first two buses.
3. **Buyer valuation separation**: Joint stability payload construction now requires explicit buyer willingness-to-pay from `maximumPreferredBuyPrice`. It no longer reuses encrypted generation cost as buyer value.

## QUALIFIED CLAIMS
- **Scalability**: Existing scalability CSVs are treated as synthetic scaffolding until generated by a reproducible runner against committed experiment configurations and raw per-seed logs.
- **Coalition Stability**: The current large-game stability path is approximate and should be presented as empirical screening unless exact core-inclusion certificates are produced for the reported cases.
- **CS-SafeMAPPO**: The title may remain unchanged, but the paper must not claim final CS-SafeMAPPO performance until the repository contains a real environment-coupled implementation, saved configurations, and raw multi-seed results.

## UNSUPPORTED CLAIMS TO REMOVE
- **Q1-ready superiority claims**: Current ablation, adversarial, and scalability outputs are not enough to support performance superiority in a Q1 journal.
- **Strategy-proofness**: Do not claim absolute strategy-proofness. Misreporting and collusion tests must report empirical attack gains under declared threat models.
- **Hardware-in-the-Loop (HIL)**: No actual physical hardware was used; all claims regarding physical effects are purely based on simulated power flow.
- **Patentability or freedom to operate**: The repository can support an invention disclosure, but patentability and freedom-to-operate require attorney review and a formal prior-art search.
