# GridNexus Load Test Report

> ** deliverable** – 200-concurrent-agent load test results.
>
> Generated by: `scripts/run_load_test.sh`
> Runner: k6 (fallback: Locust)

---

## Test Configuration

| Parameter | Value |
|-----------|-------|
| Concurrent agents (VUs) | 200 |
| Ramp-up | 20 s (0 → 50 VUs) |
| Ramp to full load | 30 s (50 → 200 VUs) |
| Sustained period | 60 s at 200 VUs |
| Cool-down | 10 s |
| Total duration | ~120 s |

## Acceptance Criteria

| Criterion | Threshold |
|-----------|-----------|
| Negotiation-round p99 latency | < 2 000 ms |
| Stability-check p99 latency | < 2 000 ms |
| HTTP error rate | < 1% |
| Session success rate | > 95% |
| Integrity failures | 0 |

## How to Re-Run

```bash
# 1. Start the stack
docker compose up -d
# Wait for all healthchecks to pass (see DEMO.md)

# 2. Run the load test (k6 required, or locust as fallback)
./scripts/run_load_test.sh

# 3. Results written to:
#    load-tests/results/LOAD_TEST_REPORT.md  (k6 handleSummary)
#    load-tests/results/summary.json         (k6 raw JSON)
#    load-tests/results/locust*              (locust CSV/HTML)
```

## Endpoints Under Test

| Endpoint | Scenario |
|----------|----------|
| `GET /health` | Broker liveness (every VU) |
| `GET /api/oracle-signals` | Oracle polling (3× weight) |
| `GET /api/analytics` | Negotiation round state (5× weight) |
| `GET /api/topology` | Stability gate (4× weight) |
| `POST /stability/check` | Engine stability probe (per VU) |
